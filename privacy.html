Privacy policy

Fitness Logger, a personal app. Last updated November 25, 2026.

What the app accesses

With the owner’s consent, the app reads daily step counts from the owner’s Google Health account, using the read-only activity and fitness scope.

How the data is used

The step count for each day is sent to a Slack workflow so it can be logged in a team fitness channel. It is used for nothing else.

Storage and sharing

The app runs on the owner’s own computer. It does not operate a server or database, and it does not sell, share or transfer Google user data to anyone. The only stored item is the owner’s sign-in token, kept on that computer.

Google API Services

The app’s use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Deleting access

Access can be revoked at any time from the Google Account permissions page, and the local token file can be deleted.
